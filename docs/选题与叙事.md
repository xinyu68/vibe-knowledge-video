# 选题与有始有终的内容

本文件是可执行的编辑方法，不是平台流量统计结论。它保留此前研究的结论与当前示例的制作经验；新热点与新事实需要重新检索。

## 先从处境选题

原理名负责解释，处境负责让普通人愿意看。先问观众遇到什么，再选知识。

| 处境问题 | 可研究方向 | 可见主体 / 事件 |
|---|---|---|
| 为什么成功经验我照做也没用？ | 幸存者偏差 | 开店、停业、记录进入统计 |
| 花了这么多，为什么还该停下来？ | 沉没成本 | 过期车票、不断追加投入、未来路口 |
| 为什么越追越累，还像在原地？ | 红皇后效应及适用条件 | 双方同时前进、移动的参照系 |
| 为什么每个人都理性，结果却更差？ | 协调问题 / 集体行动 | 排队、拥堵、各自选择的后果 |
| 为什么多一个选择，反而难决定？ | 选择负担及其研究边界 | 选择过程、比较成本、迟迟未完成 |

这些只是候选方向，不代表已经验证的普遍定律。尤其不能将存在争议或有条件的心理学结果写成“人人都如此”。

## 选题初筛

对每项给 0–2 分，比较候选题。该评分是编辑启发，不预测播放量。

1. 代入：一句话能说出观众的困惑吗？
2. 主体：第一帧能出现可识别的对象吗？
3. 事件：机制能通过动作和结果展示吗？
4. 反直觉：解释能改变观众原有判断吗？
5. 证据：核心说法有可靠来源与边界吗？
6. 闭合：结尾能回答开头并回到生活吗？

没有可靠证据、必须靠大段术语或完全无法视觉化的题目，先缩小问题或换切口。不要因一个标题热门就承担超过短片容量的论证。

## 一张故事卡完成选题

写明：目标观众、具体处境、第一句、锚词、主体、事件链、一次关键转折、原理和条件、生活回扣、结尾答案。对应模板在每期 brief.md。

一句梗概应能写成：

> 一个主体为了一个具体目标采取行动，却出现一个令人困惑的结果；观众随它找到造成差异的机制，最后用新理解重新看待最初问题。

避免纯列表式“效应的定义—三个例子—总结”。内容需要观众关心的结果和结果产生的过程。原理名不应替代解释。

## 按音乐分配任务

| 段落 | 核心任务 | 段尾留下什么 |
|---|---|---|
| 开场 | 主体立即进入矛盾 | 想知道它会怎样 |
| 蓄势 | 观察到反常或信息缺口 | 旧解释不够用 |
| 首高潮 | 用锚词揭晓共同处境 | 愿意追问为什么 |
| 故事与机制 | 展示起因、操作、不同后果 | 看懂关系 |
| 边界与辨析 | 说明条件和未知 | 不过度套用 |
| 回到生活 | 同一原理解释观众处境 | 获得新的判断方式 |
| 尾奏 | 回答开头，重定义锚词 | 留下理解与余味 |

不要把所有题目强制塞入同样秒数。音乐平稳段适合解释；段落展开适合揭晓；回落适合反思。故事先完整，再按乐句压缩。

## 让每一屏产生进展

逐屏填写“这时观众多知道了什么”。可能是新线索、新问题、一个选择、一个结果、一个解释或一种新的看法。相邻两屏完全重复时，合并或改写。

用动作把抽象关系落地：报名后进入名单、受损后失去动力、离开后不再进入记录。字幕负责解释为什么值得注意；不要只给名词贴标签。

## 结尾闭合检查

- 开头的问题是否被直接回答？
- 开头的主体或场景是否回场，而且观众看法改变了？
- 锚词是否获得新含义？
- 生活回扣是否使用同一种机制？
- 有没有未经论证的“所以你只要……”建议？
- 观众能带走的是判断方法，还是空泛口号？

《没回来的飞机》的闭合是：从“危险伤口为什么看不见”出发，展示返航条件筛掉部分信息，再回到店铺与个人判断，最后让“缺席”从记录的缺口变成判断时应考虑的一部分。

## 来源与表达

片中每个年份、人名、统计、引文都进入 research.md 的核对表。原始材料支持什么就说到哪里。示意的 6 架飞机、A–F 编号、弹孔位置和经营小店不是真实统计；应有简明标记，且不能拿示意反过来“证明”事实。

如引用历史故事，区分原论文、后人重印与通俗转述。示例使用 CNA 的沃尔德研究重印材料；1980 是重印年份，不是把二战事件改到 1980。历史来源详见示例 storyboard.md 和 docs/history。
