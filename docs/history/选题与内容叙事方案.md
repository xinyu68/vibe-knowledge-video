# Vibe 知识大赏：选题与内容叙事方案

版本：1.0  
整理日期：2026-10-23

与《通用制作方案.md》配合使用：本文件解决讲什么、为什么值得看、怎样持续推进、怎样有始有终；制作方案负责音乐、画面、转场和交付

配套：《选题库与故事卡模板.md》提供候选题和可填写的故事卡

## 一、这套方案的结论

每条片子都要交付三样东西：

1. **开头让观众在意的具体问题**
2. **中间使他改变理解的证据或过程**
3. **结尾对开头问题的明确回答**

情绪、音乐和动效用于加强这三件事。漂亮片名、术语介绍和一句金句不能替代它们

选题流程：

> 找到观众的具体处境或可观察现象 → 写出一个问题 → 查证 → 确定结尾答案 → 选锚词和贯穿物件 → 倒推故事与证据 → 对齐音乐 → 写分镜

所有评分、时间建议和筛选阈值都是本方案的编辑工具，不是平台算法规则，也不保证播放量

## 二、搜索依据，以及能推断到哪一步

本次检索结合了创作者原帖的标题和公开文案、平台官方创作说明、原始研究。视频原帖未全部成功打开播放器，因此不声称完成这些案例的逐镜视听分析，也不编造原片的重拍时间

### 1. 可借鉴的内容入口

| 原帖或资料 | 能核对的内容 | 本方案提取的做法 | 不能据此声称 |
|---|---|---|---|
| [《银牌的眼泪》](https://www.bilibili.com/video/BV12DHQ61EhT) | 标题和文案用错过交通工具、成绩差距、未说出口的话引出“差一点” | 先给观众经历过的处境，再引出知识问题 | 单靠这种开头就能复制传播结果；所有银牌获得者都比铜牌更难过 |
| [《剃刀》](https://www.bilibili.com/video/BV1WkJk6VEqA/) | 公开简介用已知点的拟合与新点的到来形成结果变化 | 让观众先作预测，再用新证据重新判断 | 简单模型总能胜出；0.8 的五次方适用于任意相依事件 |
| [《信息论·惊奇之学》](https://www.douyin.com/video/7690337875291950345) | 公开文案从熟悉的诗句填空转向无法预测的下一句话 | 让观众亲自体验差别，再给概念命名 | 已经逐帧验证了它的动画和音乐安排 |
| [信息论与熟悉表达的案例](https://www.bilibili.com/video/BV1VVpo6gEMw) | 标题和简介把信息论与熟悉的情感表达连接 | 日常关系可以成为抽象知识的入口 | 信息量等于感情价值，或可预测的话没有意义 |

页面中的播放、点赞、账号规模会变化，且口径不完全相同。本方案不固定记录这些数字，也不把题目与传播量之间的相关性说成因果

### 2. 平台经验与研究支持

- [YouTube 官方创作者访谈](https://blog.youtube/creator-and-artist-stories/youtube-shorts-deep-dive/)讨论开场抓住注意力、引发好奇、给予满足。这是 Shorts 创作者经验，可借鉴到信息流入口，但不能把“一秒”当作所有长短视频的统一定律
- [YouTube 官方留存说明](https://support.google.com/youtube/answer/9314415?hl=en)强调开头与标题封面的预期一致，并用留存曲线识别跳过、离开和重复观看。重看峰值也可能表示内容没讲清楚，需要回到画面判断
- [Gruber、Gelman 与 Ranganath，2014](https://pmc.ncbi.nlm.nih.gov/articles/PMC4252494/)在实验中观察到对高好奇问题答案的记忆收益。它支持“让人先对问题感兴趣再给信息”这一方向，但不证明某种短视频钩子必然提升留存或播放量
- [Arkes 与 Blumer，1985](https://cognition.aau.at/bg/BA/Arkes%20%26%20Blumer%201985.pdf)研究沉没成本效应，为本方案后面的《舍不得》示例提供机制依据。示例中的影院情节是原创演示，不是该研究中的真实实验记录

以下流程是根据上述资料与本次制作反思提出的创作建议；没有做跨平台统计验证

## 三、选题：从观众的问题出发

### 1. 一条片只服务一个具体问题

先填这句话：

> 这条片给【哪一类人在什么情境下】看，回答【哪个具体问题】，让他看完能够【复述什么／重新判断什么】

例如：

- 太宽：给普通人讲沉没成本
- 可制作：给明明已经不喜欢、却因为花过钱而继续的人看，解释过去投入怎样干扰眼前选择
- 太宽：讲概率论
- 可制作：用一次可亲自猜结果的实验，解释为什么单次难预测、长期分布却可能出现规律

同一条片不要同时解释一个理论的历史、全部实验、所有应用和人生意义

### 2. 五类内容入口

| 类型 | 观众为什么关心 | 可视化方向 | 结尾要交付什么 |
|---|---|---|---|
| 经常经历的困惑 | 我一直这样，却不知道为什么 | 电影票、闹钟、聊天窗口、排队等具体物件 | 一个解释和适用的判断问题 |
| 直觉与结果冲突 | 我以为会这样，结果却相反 | 两条路径、两种策略、同条件对比 | 解释使直觉失效的条件 |
| 可以立即参与的测试 | 我想看看自己会不会猜错 | 填空、选择、计数、预测下一步 | 回答测试，并解释结果 |
| 普通东西的隐藏机制 | 天天看见，却没有认真想过 | 从物件进入内部结构或过程 | 重新看懂眼前的物件 |
| 有证据的历史问题 | 一个人怎样发现或解决它 | 一件档案、器物、实验或记录 | 回答最初的历史问题，交代未知部分 |

人文处境适合引发代入；自然现象和数学实验可以靠惊奇吸引人。不是每个科普选题都要落到爱情、焦虑或“改变人生”

### 3. 吸引力来自可验证的落差

优先寻找：

- 付出与结果的落差
- 感觉与事实的落差
- 局部与整体的落差
- 看得见与被遗漏的落差
- 过去投入与未来选择的落差
- 表面简单与内部机制的落差

落差要能被后面的证据解释。不要先写夸张结论，再寻找能凑上的理论

## 四、选题评分与淘汰

每项按 0～5 分评估，再按权重折算。它只用于比较自己的候选题，不预测平台分发

| 维度 | 权重 | 核心问题 |
|---|---:|---|
| 具体关联 | 20 | 一类观众是否真的遇到这个问题，或能立即参与？ |
| 问题张力 | 20 | 观众知道什么，又缺少哪一块，为什么想知道？ |
| 可演示性 | 20 | 原理能否通过具体物件和动作被看懂？ |
| 证据质量 | 15 | 核心结论有可核对的原始材料和适用条件吗？ |
| 叙事闭合 | 15 | 结尾能否明确回答开头，并回到同一物件或处境？ |
| 表达新意 | 10 | 比已有作品多了哪个新问题、证据或视角？ |

总分 = 各项“得分 ÷ 5 × 权重”之和

内部建议：75 分以上进入故事卡；60～74 分先改问题或找新画面；低于 60 分暂缓。阈值是工作习惯，后续用实际内容反馈修订

以下任一项不满足，不能直接进入成片：

- 核心结论无可靠证据，或事实尚未查明
- 标题和开头许下的答案，结尾无法兑现
- 主要解释只能靠长段字幕，画面只是装饰

不是题目越难越值得做。第一批优先选能用一个物件、一个机制、一次可观察变化讲清楚的题

## 五、标题、开头、答案必须讲同一件事

写作前先填三句话：

1. **标题给出的期待**：观众以为自己将理解什么
2. **开头问出的主问题**：这一刻他具体想知道什么
3. **结尾给出的答案**：看完能够用一句人话回答什么

如果三句对不上，先改选题，不进入分镜

例：

- 题目：《舍不得》——为什么不想看了，还不离场？
- 主问题：明明接下来并不想继续看，过去花的钱为什么仍把我留在座位上？
- 答案：已经无法收回的投入，可能把我们继续投入的意愿拉高；下一步仍要比较从现在起的成本与价值

结尾可以再给一个开放问题，但知识上的主问题必须先回答。不能用“你怎么看”代替解释

## 六、先确定终点，再写开头

终点不是一句口号，而是三项明确变化：

| 层面 | 写清什么 |
|---|---|
| 理解 | 观众现在知道了哪一个原因、条件或机制 |
| 画面 | 开头物件再次出现时，改变了哪一处 |
| 情绪或判断 | 观众如何重新看待开头的处境，或接下来会多问哪一个问题 |

先写一个不追求文采的答案，确保逻辑成立；再设计回场画面；最后才润色结尾字幕

不要让“有触动”变成强制正能量。可以是理解、惊奇、遗憾、释然或一个更准确的问题，不必全部导向成功和自我提升

## 七、前三秒：给具体反应，不给空泛预告

开头优先使用以下方式，按主题选一种，不混用一堆手法：

| 方式 | 第一镜做什么 | 观众会在心里做什么 |
|---|---|---|
| 选择 | 摆出两种明确选项 | 先选一个 |
| 预测 | 一个过程停在关键结果之前 | 猜下一步 |
| 熟悉处境 | 画出他经历过的一个动作 | 认出自己 |
| 小测试 | 给出可立即完成的观察任务 | 参与一次 |
| 反常结果 | 显示一个真实、可解释的结果 | 追问为什么 |
| 隐藏代价 | 把选择看不见的一面呈现出来 | 重新衡量 |

钩子要与后文共享同一个问题。不要用与主题无关的灾难、惊悚、夸张数字或关系焦虑把人骗进来

0～3 秒是本系列的编辑目标，不是已验证的流量公式。文案、画面和音乐要共同完成这一目标，不能只有一句“震惊”的字幕

## 八、中段：持续前进，而不是不断抛新谜语

一条片保留一个主问题；它可以拆成少量递进问题，但不能把许多未解悬念同时挂着

推荐的推进方式：

> 先给现象 → 让观众形成判断 → 出现新证据 → 修正判断 → 演示原因 → 交代边界 → 回到原问题

每一段回答一个旧问题，再自然产生下一个问题。不是一直拖到片尾才给任何回报

### 三种可选故事结构

| 题材 | 结构 |
|---|---|
| 选择、行为和日常困惑 | 一个处境 → 做出选择 → 发现代价 → 看见机制 → 比较另一种选择 → 回到同一处境 |
| 数学、自然和工程现象 | 看见现象 → 作出预测 → 观察结果 → 找到关键变量 → 当场验证 → 给出解释和条件 |
| 历史和知识发现 | 一个未解问题 → 原始材料中的尝试 → 关键发现 → 后果与局限 → 回答开头问题 |

历史记录没有某人的想法或对话时，不虚构独白来补戏剧性。演示、改编和复原需要明确区分

### 每一段至少改变一件事

- 我看到了新的证据
- 我原来的解释遇到困难
- 我看懂了关键步骤
- 我知道这个结论的条件
- 我能把它用回开头的具体问题

若一整段都没有这些变化，只是在换背景、增加术语或重复同一句话，就删掉或重写

## 九、第 17 秒交付第一份回报

本目录默认《千年之后》“原谅他7次”版在约 17.03 秒出现明显能量上升，第一次高潮先按第 511 帧（17.033333 秒）设计，再以带音乐样片试听确认；换音乐按实测落点调整。文件与版本见 `背景音乐说明.md`

这一次应该兑现“继续看值得”的第一份承诺：

- 让被忽略的部分进入视野
- 让两个看似无关的场景显出同一种结构
- 让观众看到自己刚才的判断会产生什么结果
- 把已经体验到的困惑凝成锚词

锚词落下只是命名。真正的回报是画面让观众多明白了一件事

后面还有空间解释为什么，以及如何划定边界。不能让前 17 秒只负责堆情绪、17 秒后突然开始另一部无关的讲义

## 十、内容有始有终：五项闭合

| 闭合项 | 开头留下什么 | 结尾必须做什么 |
|---|---|---|
| 问题闭合 | 一个具体疑问 | 明确回答，或说明证据为何暂不能给确定答案 |
| 因果闭合 | 一个反常现象 | 给出看得懂的机制或已知解释，避免只贴术语 |
| 物件闭合 | 一个有记忆点的物件和状态 | 同物件回场，只改关键一处，让变化有含义 |
| 期待闭合 | 标题和前半段承诺的收获 | 不换题，不把最初问题遗忘 |
| 情绪闭合 | 处境中的困惑、遗憾或好奇 | 给理解或余味，不在音乐结束时突然截断 |

结尾可以保留新的思考，但不要遗留本片本该解决的主要疑问

写完做一个检验：

> 把开头最后一个问句，和结尾的回答单独放在一起。它们能构成真正的问答吗？

再做第二个检验：

> 如果删掉片名和金句，只看中段证据，答案还成立吗？

## 十一、完整示例：《舍不得》

这是故事结构示例，不是已制作成片，也不冒充真实实验。电影是否不值得继续看、是否不可退票等条件需要在演示中明确

### 故事卡

- 观众：明明已经不喜欢，却因为付出过而继续的人
- 范围：先用一张不可退的电影票解释机制，不替观众决定工作、关系或其他复杂选择
- 主问题：你已经不想看了，为什么还不走？
- 锚词：舍不得
- 物件：一张电影票
- 核心答案：已经无法收回的投入，可能影响继续投入的意愿；是否继续，还需比较未来的价值与代价
- 回场变化：票还在，人却可以重新决定下一小时怎么过
- 边界：可退费用、履约责任、未来收益、转换成本等仍可能与决定有关

### 有起有落的内容路线

| 阶段 | 观众在问什么 | 画面发生什么 | 内容给出什么 |
|---|---|---|---|
| 开场 | 不想看了，为什么不走？ | 手捏电影票，视线在银幕与出口之间停留 | 具体处境 |
| 困惑扩大 | 是电影好看，还是票钱不甘心？ | 票价留在票上，接下来的时间一点点流逝 | 过去投入与未来时间的区别 |
| 首次高潮 | 到底舍不得什么？ | 镜头拉开，过去的票款留在一侧，未来的时间在另一侧展开；锚词落下 | 第一份回报：两种东西被分清 |
| 证据与演示 | 过去花的钱怎样改变选择？ | 在明确设定下比较不同已付价格，但相同的后续体验 | 让机制被看见；研究与情境演示分开 |
| 解释 | 继续坐着，能把过去的钱变回来吗？ | 不论下一步怎样，已经不可退的票款保持不变 | 无法收回的部分与未来选择分开评估 |
| 边界 | 那所有坚持都该放弃？ | 加入仍有价值的后续体验或可退条件，重新比较 | 坚持与离开都需要看未来条件 |
| 回场 | 那这一刻，你愿意怎样过？ | 同一张票收进口袋，人物重新作出选择 | 开头问题得到回答 |
| 尾声 | 遗憾是否必须立刻消失？ | 票没有消失，人物走向自己选择的位置 | 可以仍然心疼，但不必让它替你做完决定 |

结尾字幕方向：“你还是心疼票钱，但愿意走了。”这只是特定情境下的原创结尾，不是“任何情况都应该离开”的结论

### 这个故事为什么闭合

开头是选择困难，机制解释了困难从哪里来，边界避免把它讲成放弃口号，结尾回到同一张票和同一个选择。画面、知识与情绪服务于同一个问题

## 十二、避免“知识包装的人生口号”

以下表达容易吸引注意，但会破坏内容可信度：

- 把信息量低，讲成感情没有价值
- 把局部最优的数学示意，讲成现实里吃苦必有回报
- 把熵增，讲成所有关系必然变坏
- 把概率模型，讲成人生有一个保证正确的选择比例
- 把幸存者偏差，讲成所有成功经验都没用
- 把平均实验结果，讲成每个人必然如此

每次生活迁移都回答：相同的结构是什么？不同的条件是什么？研究证明到哪里，哪些只是有用的类比？

感动可以来自“原来如此”，不必通过夸大结论制造

## 十三、选题生产流程

1. 收集具体困惑：评论中的真实提问、生活观察、读书笔记、研究材料、自然现象
2. 每个困惑生成 2～3 个不同问题角度，不先堆术语
3. 初查事实和已有作品；相同知识点至少提出一个新的切口或演示
4. 用六维评分筛选，保留少量候选
5. 给推荐题填写故事卡：观众、问题、答案、证据、锚词、物件、边界、回场
6. 写标题、开头承诺、结尾答案三句，检查是否一致
7. 先排内容因果链，再把段落放到实际音乐中
8. 写完整分镜并制作 0～22 秒样片
9. 修正后铺全片，逐项检查五种闭合
10. 发布后用实际数据和反馈修订下一条的选题与表达

题目本身已经成立时，再增加动效；不要用更昂贵的画面掩盖一个没有答案的问题

## 十四、发布后的内容复盘

有后台数据时，结合本平台实际可用的指标检查：入口留存、平均观看时长、关键段落流失、重复观看、收藏分享、评论中的理解程度

| 观察到的信号 | 优先核对的内容问题 | 不应直接下的结论 |
|---|---|---|
| 前几秒离开多 | 标题预期、首句、第一镜是否能理解 | 一定是选题没人喜欢 |
| 片名或高潮后掉得多 | 期待是否已耗尽，后面是否突然转成讲义 | 高潮必须继续加大 |
| 中段某处掉得多 | 概念跳跃、重复、读不完或没有进展 | 观众都不愿学习 |
| 某段重看明显 | 是否值得回味，还是没看懂 | 重看就一定说明这一段优秀 |
| 评论只谈音乐画面 | 是否记住了本片的知识问题和答案 | 评论少讲知识就一定失败 |
| 评论反复问已解释的问题 | 解释是否太快、术语是否替代了动作 | 必然是观众不认真 |

比较时尽量选择同平台、相近时长、相近受众的作品。分发渠道和受众差异会影响结果，不能仅凭一条视频的绝对播放量判断方案有效

每次修改优先围绕一个明确假设，如“开场问题不够具体”或“机制演示没讲清楚”。保留修改前后的记录，不靠印象反复换题

## 十五、内容验收清单

- [ ] 能说清这条片具体给谁看、回答什么
- [ ] 标题、开头主问题和结尾答案一致
- [ ] 核心结论有来源，类比与证据分开
- [ ] 第一镜给具体物件和动作，不让观众等待介绍
- [ ] 第一高潮给出有意义的进展
- [ ] 中段每一段都回答问题、增加证据或修正理解
- [ ] 术语出现之后，机制仍通过画面讲清楚
- [ ] 结尾直接回应开头，不只重复金句
- [ ] 开头物件回场的变化与答案有关
- [ ] 生活应用没有超出证据和适用条件
- [ ] 删除装饰性标题后，内容依然讲得通
- [ ] 用普通人的话能复述：“我原先以为……现在知道……因为……”
