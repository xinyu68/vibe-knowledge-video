# 新电脑首次使用

先安装 Python 3.10+，并在 Codex 中打开克隆后的项目目录。Windows 默认支持 Windows 10/11 x64；Codex 本身的登录、模型选择和文件／网络权限按新电脑实际情况配置，仓库不修改这些设置。

## 一个初始化入口

在项目根目录运行：

```shell
python bootstrap.py
```

macOS / Linux 可将开头改成 `python3`。该命令会：

1. 在项目内创建 `.venv`，安装渲染和内置 Edge 配音依赖。
2. 检查 FFmpeg 与 FFprobe 能否运行。Windows x64 缺少时自动下载校验过的发行包，保存到 `.local/ffmpeg/bin`；仅修改运行进程的 PATH，不改系统环境变量。macOS/Linux 缺少时给出安装指引，不自动请求管理员权限。
3. 将 Playwright Chromium 安装到项目的 `.local/browsers`，用这份浏览器验证首次渲染。
4. 检查字体、音乐、Skill 和本地依赖。
5. 现场合成一句云健中文旁白，生成简单动画和测试配乐，导出十秒1080p/30fps MP4，并检查完整解码、时长、同步、真峰值和片尾抽帧。

Windows FFmpeg 使用 [Gyan 的发行构建](https://www.gyan.dev/ffmpeg/builds/)，下载URL与SHA256固定在 `bootstrap.py`；来源和校验记录保存在本机 `.local/ffmpeg/download.json`。Python 包从当前 pip 配置的包源安装，浏览器由 Playwright 安装。

首次安装需要联网，Edge 配音需要能连接其语音服务，不需要 API key。失败时显示具体阶段，修复后重跑同一命令；已有依赖可复用。不复制其他电脑的 `.venv`，不需要安装个人 ttsCN Skill。

## 如何确认成功

初始化最后输出 `self-test.json` 的结果。只有 `ok: true` 且 `fresh_online_synthesis: true` 才表示本次完整技术链路验证成功。最新记录在 `.local/self-test-latest.json`，其中的 `video` 指向实际测试MP4。

每次自检新建 `.local/self-test-<时间>-<随机标识>/`，不沿用旧配音缓存、不写入 `videos/`、不覆盖创作影片。测试图形和合成音仅用于技术验证，不进入创作素材库。自检不会自动判断叙事质量，也不声称完成主观试听。

安装完成后用项目解释器运行：

```powershell
# Windows
.\.venv\Scripts\python.exe vibe.py doctor
.\.venv\Scripts\python.exe vibe.py doctor --online
.\.venv\Scripts\python.exe vibe.py self-test
```

macOS / Linux 使用 `.venv/bin/python`。Windows 也可用 `./vibe.ps1 doctor` 等入口。

- `doctor`：本地检查；`online_synthesis: not_tested` 表示还未验证语音网络，不能当成已接通配音。
- `doctor --online`：另现场合成一句测试语音，报告成功或失败。
- `self-test`：重新跑完整十秒链路。
- `python bootstrap.py --skip-self-test`：只准备环境；适用于先安装依赖的情况，不声明配音网络或完整链路已通过。

如果浏览器有系统库缺失，Linux 可按 Playwright 错误提示安装依赖；不要把安装失败的浏览器标为可用。已有Chrome可供日常渲染使用，初始化默认验证刚下载的Chromium。需要指定时可在当次进程设置 `VIBE_BROWSER=chromium` 或 `VIBE_BROWSER=chrome`，默认 `auto`。

## 接下来交给 Codex

```text
读取 AGENTS.md 和 .agents/skills/vibe-video/SKILL.md。
先检查这台电脑的制作环境；首次使用时按 docs/新电脑启动.md 完成初始化和十秒自检。
由当前会话负责制作，不启动制作 Agent 团队。
这次先讨论题目：{题目或方向}。确定认识和思路后再开始创作。
```

新旁白直接运行 `python vibe.py narrate <slug>`；工具使用项目内 Edge 实现，保存原始声音、词边界和缓存签名。只有复现旧环境或需要其他已配置后端时，才显式传 `--tts-cli <外部脚本>`。字幕与动作仍需要按实测声音设计，合成成功不等于自动对齐或听感通过。
