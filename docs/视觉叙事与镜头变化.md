# 视觉叙事与镜头变化

本规范用于解决“单个镜头有动画，连起来却像同一物件的功能展示”的问题。与[制作方案](制作方案.md)、[选题与叙事](选题与叙事.md)、[渲染与验收](渲染与验收.md)一起使用。由当前会话按本规范设计分镜、检查实际画面与全片节奏，并完成返修；没有自动审美评分。

## 1. 让同一个问题贯穿全片

贯穿全片的是观众追问的问题、因果过程或可以追踪的经历。具体物件可以作为线索，但不必一直位于画面中央，也不必始终占据主要画面。

例如以手机引出“为什么得到想要的东西，快乐却没持续多久”，手机可以承担开场和结尾；中段应按叙事进入真实生活空间、可见行为和机制说明。旅行、住处或人与环境的变化不能都缩成手机屏幕里的卡片，否则观众仍在反复观看一个手机外框。

每个镜头先回答：此刻发生了什么，观众比上一镜多知道什么？再选择最能展示它的主体、空间、景别和动作。不能先复制上一镜的物件居中布局，再把新文案塞进去。

同一主体连续出现可以成立：追踪一个动作、比较改变前后、保留反例或回收伏笔时，都可能需要复现。检查的是叙事有没有推进，不以换主体次数评判质量。

## 2. 区分画面变化与装饰变化

| 维度 | 能推动理解的变化 | 不能单独算作推进的变化 |
|---|---|---|
| 主体与行为 | 从购买选择进入使用后的实际行为，结果可见 | 同一物件上下浮动，周围出现新图标 |
| 场景与空间 | 从桌面进入房间、街道或目的地，空间参与事件 | 仍在手机内播放旅行图片，外框和构图不变 |
| 景别与构图 | 特写看见细节，拉开后揭示细节与整体的关系 | 只轻微放大缩小，信息始终相同 |
| 时间与状态 | 同一处境经过明确时间变化，人物或对象状态产生差异 | 换一行日期或一张壁纸，主体没有可读反馈 |
| 机制与证据 | 原因先发生，关系或结果随之改变，揭示反直觉之处 | 只出现术语、曲线或抽象光圈，没有对应过程 |
| 情绪与结果 | 期待、获得、习惯等状态由行为和环境表现 | 全程用同一种光效表示所有情绪 |

这些是设计维度，不是每镜必须全部变化的清单。按故事需要组合，保留观众识别人物、物件和因果关系的线索。不能为了丰富而随机换景，或把同一机制尚未核实的生活例子拼成蒙太奇。

深色风格继续保留明暗层次与有含义的冷暖对比。颜色含义在片内一致，主体清楚、字幕可读；不能靠不断换色代替状态变化。人物只在其行动确有叙事作用时出现，沿用已确认的造型和动作要求。

## 3. 转场把观众带到下一层信息

转场设计同时写出“承接什么”和“落到哪里”：前一镜的动作、方向、形状、声音或因果关系怎样带入下一镜，下一镜新增什么空间、状态或证据。

- 手机里的旅行照片可以经短暂推进进入真实场景；转场完成后撤去手机边框，让环境中的事件成为主体。
- 包装盒打开的一道光可以接到窗边的日光，但下一镜要展示住处或日常行为的变化，不能只换成另一张产品图。
- 一条运动轨迹可以接到机制示意中的关系线；先建立两者对应，再让示意图解释刚才看见的结果。
- 结尾可以回到开场同一物件或构图，用改变后的行为或判断回答开头。明确这是认识变化后的复现，而不是填补时长。

以上只是镜头连接方法，不是每期必须使用的效果。相同物件、线条或光源只承担短暂连接，不要求前后整场都使用相同外框和居中构图。短而干净，动作与相机连续；保留现有的音乐落点、高潮留白和字幕可读性要求，不通过快切或增加粒子制造忙碌感。

## 4. 手机题材的改写示例

下面是视觉叙事示意，不能当作心理学研究证据，也不是对所有人的快乐变化作断言。具体机制、生活例子的适用性、时间与数字都须在本期 research.md 核对；无法支持的结论应缩小或删除。

| 叙事任务 | 场景与可见事件 | 与前一段的连接 | 这一段新增什么 |
|---|---|---|---|
| 建立期待与困惑 | 购物选择、包装打开、新物件首次进入生活；尽快给出获得后仍有困惑的反差 | 选择动作连接到实际获得 | 具体愿望与实际结果之间的问题 |
| 走进真实日常 | 将叙事需要的住处、出行或旅行场景展开为完整空间，展示相应行为 | 屏幕中的形状或照片只作入口，外框随后退出 | 愿望如何落实到真实经历；不堆无关生活片段 |
| 呈现变化 | 在有明确时间线索的日常中比较相似事件前后的反应，保留可比条件 | 同一动作或环境细节帮助识别前后关系 | 哪个反应改变、哪个条件没变 |
| 解释机制 | 从已看见的变化进入简化示意，把生活观察与机制一一对应 | 抽取刚才的对象或关系进入示意 | 为什么原先直觉不足，以及解释的边界 |
| 回到开场 | 回到最初物件或选择，展示有依据的新理解如何影响判断 | 回收开头的形状、动作或问题 | 回答最初困惑，避免临时添加励志口号 |

真实场景、局部细节、机制示意和回场各自承担任务，不要求平均分配时长，也不设手机出镜比例或固定场景数量。实际节奏服从文案、音乐和理解过程。

## 5. 精做前先看全片

### 分镜总览

在本期 storyboard.md 为每个镜头记录下表，时间码覆盖全片。拆镜依据叙事事件，不按每条字幕机械拆镜。

| 镜头 ID / 时间码 | 场景与空间 | 主体及行为 | 景别 / 构图 | 新增信息与叙事任务 | 转场承接 → 落点 | 与相邻镜头的重复及保留理由 |
|---|---|---|---|---|---|---|
| 待填写 | | | | | | |

把全片关键镜头按时间顺序排成缩略图总览，并标明镜头 ID 与时码。先不读字幕，看主体轮廓、空间和布局是否长期相同；再读叙事任务，检查变化是否有用。可统计重复主体、构图和停留时长来发现风险，但这些数值不直接决定通过或失败。

### 完整动态粗剪

精做前用简化形状、占位场景和基础动作完成从开头到片尾的动态粗剪，包含完整旁白、音乐与关键音效，沿用本片真实时间轴。现有工具仍使用 1920×1080、30fps，先降低材质和装饰复杂度；不能缩短空档或删去中段来掩盖节奏问题。粗剪需要展示事件开始、过程、结果及转场落点，静帧轮播不能代替。

通过本期播放器连续审查，或使用[本地粗剪与检查工具](本地粗剪与检查.md) `python -m tools.video_review animatic <slug>` 导出 `build/animatic/animatic.mp4` 及总览证据。在本期 visual-review.md 记录相对路径、对应版本及播放方式；播放器若只播放原曲，须先接入完整混音才能审查旁白与画面的配合。基础 `vibe.py` 没有同名或低清导出参数，不能杜撰参数或覆盖已交付成片。单独的无声 render 片段也不等于完成音画审查。

当前新片模板可先执行 `mix <slug>` 生成完整混音，再执行 `serve <slug>` 用播放器审查简化场景；完整命令与刷新、版本核对要求见[渲染与验收](渲染与验收.md)。这条草稿审查路径不要求先声明 production_ready=true。

完整观看粗剪时检查：前几秒是否出现矛盾；解释阶段是否看见过程；转场后是否进入了新信息；是否有连续多段保持同一构图；旁白是否推进故事；音乐舒缓处是否有观察价值，高潮是否形成真实释放。发现结构问题先改脚本或分镜，再做材质、光效与细节动画。

## 6. 全片审片与返修

由当前会话在分段实现后单独复核完整粗剪，并集中查看全片总览；不把自查称为独立第三方审查。分段检查可以发现局部错误，但不能替代全片判断；不能只凭“每段都有动画”和“转场很顺”就判定整体丰富。

在本期 visual-review.md（新片使用项目同名模板）记录总览、完整动态粗剪与以下审片结果；输出目录中已有的 review/人工复核.md 可链接到这份记录，避免维护两套互相矛盾的结论：

| 版本 / 文件 | 时间码范围 | 实际看到或听到的问题 | 对理解或节奏的影响 | 修改位置与措施 | 复查证据及结论 |
|---|---|---|---|---|---|
| 待填写 | | | | | |

审片至少回答：

- 遮住字幕后，哪些段落仍像同一物件的连续展示？这些复现是否承担比较、追踪或回收任务？
- 生活事件是否真正发生在空间里，还是一直被装进手机、卡片、仪表盘等同一个容器？
- 转场前后哪个条件、空间或认识发生了变化？是否只换了屏幕内容？
- 哪些动画展示了原因与后果，哪些只是装饰？删掉装饰后事件是否仍成立？
- 结尾是否回到开头的问题，并用片中已经建立的认识回答它？
- 连续观看时，旁白、音乐和动作是否互相等待过久，或在重要结果出现前就抢先解释？

未通过时写明具体时码和返修目标，回到对应脚本、分镜或动作代码；已有完整制作授权内自主修正，无需逐项请求批准。修改后复查受影响镜头、前后衔接及全片节奏，不能沿用旧版本的审片结论。

记录实际查看的文件、版本或哈希、区间及试听范围。无法连续播放、只看过抽帧或没有试听时，明确记为尚未完成相应主观检查，不把文件存在或技术检查成功当作已审完整片。粗剪通过后，正式成片仍需按渲染与验收文档检查编码后的画面、字幕和声音。

本规范定义制作与编辑要求。production_ready、源码签名、文字边界和音轨检查不会自动识别视觉重复。当前会话的判断必须有具体画面依据和实际检查范围，不能把文字自评或程序通过当成审美保证，更不能据此保证播放量或完播率。

当前会话连续负责分镜、代表性样段、全片粗剪、定向精修和成片复查。样段先检查开头、人物/手部造型、接触关系及机制解释，再扩展其他镜头；粗剪保留全部真实声音和时长。一次列清必要返修，优先修影响认识、主体可读性和动作连续性的问题。
