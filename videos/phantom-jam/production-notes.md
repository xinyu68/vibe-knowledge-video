# 《没有事故，为什么突然堵了？》制作记录

日期：2026-10-28。状态：成片编码、技术检查及编码后图像复核完成，已通过官方飞书CLI发送。

## 内容与视觉

围绕“无形的墙”，用同一辆金色车串起突然停下、理解拥堵波、驶出慢行区及回看整支队伍。真实研究与机制示意分开标注，来源和片中年份/数字见 research.md。2008为论文发表年；22辆和230米来自原论文，影片不声称使用原实验录像。

world.js 使用本地Canvas绘制透视车辆，有车身、玻璃、轮胎、灯和阴影；traffic.js 用说明用 IDM 模型驱动位置、速度、车灯和车轮。车辆按轨迹切线朝前，停车后轮子停转。数值积分步长0.025秒；期望时间车距T=0.9秒、期望速度14米/秒、最大加速度0.6米/秒²、舒适减速度1.4米/秒²、静止间距2米、车长4.6米。这些仅为动画参数，不是论文实测值或驾驶建议，且T不是显式反应时延。

密集队列22辆，较疏对照14辆，同为230米环路、同一0.15米位置微扰。加速度限幅为−5至2米/秒²，积分采用非负速度与停车距离处理；这些也是演示模型的简化。动画压缩模型时间；直路镜头将环路局部展开以展示相邻车辆，不能据此推断真实公路波速或拥堵持续时间。validate_model.js 检查车辆不倒退、不重叠、低速区逆向传播以及金车确实停下并重新驶出。

## 配音与音乐

Edge 云健 zh-CN-YunjianNeural，640汉字、10个完整语义段落、正常语速。41条双语字幕按原生词级边界独立拆分，中文最长16字，最短停留约1.988秒。结尾人声150.85秒结束，尾奏保留约8.4秒。普通段间可听空隙中位数约0.525秒；16.4–17.9秒没有旁白样本。依据见 audio/timing-audit.json。

音乐为项目已有《千年之后（氛围版）》原谅他7次，解码159.250秒。固定−18dB增益，music_mode=constant，包络最小/最大均为1，不按每句话升降；轻环境层及7处短音效。第511帧（17.033333秒）揭晓锚词，与冲击音效同点。旁白整轨−18.0 LUFS，没有变速拉伸。音频测量不能代替主观试听；本次没有声称主观听完整片。

## 本地重建

从仓库根目录运行，`python` 使用项目虚拟环境。除 README 中的 Python、Playwright、FFmpeg/FFprobe 外，`validate_model.js` 需要可从 PATH 调用的 Node.js；它只用内置 `fs`、`path`，无需安装 npm 包。普通预览、混音、渲染使用浏览器内的 JavaScript，不依赖该 Node 检查脚本。

```powershell
python videos/phantom-jam/timing_build.py
python videos/phantom-jam/prepare_release.py
node videos/phantom-jam/validate_model.js
python vibe.py mix phantom-jam
python vibe.py preview phantom-jam
python videos/phantom-jam/review_episode.py
# 实际查看预览与动作序列，修正后重新预览。
python vibe.py render phantom-jam --jobs 4
python vibe.py finalize phantom-jam
```

已有配音缓存可离线混音，生成新声音时按项目配音流程当次传入 ttsCN CLI 路径。配置和源码没有固定本机盘符或用户目录。服务仅绑定127.0.0.1。

本目录是已完成的工程示例。`timing_build.py` 会重写本期 narration.json、plan.json 和音频时序报告；它的 P01–P10、故事坐标、首高潮保护区和尾奏检查均针对本片。`prepare_release.py` 也会覆盖本期抽帧、音效和制作状态。原音频缓存完整时可用这些脚本复建本片；换选题、修改配音或更换音乐时，应先重新设计并校对对应映射，不能把这两个脚本当作任意主题自动对齐器。

`audio/narration/P01` 至 `P10` 保存原始 WAV 和与正文、音色、语速匹配的元数据；词边界覆盖本段原文。`subtitle-script.json` 的每行分别是原声文本片段、精炼中文字幕、英文翻译，不能用精炼字幕去猜原声字符位置。字幕匹配使用词级时间戳，多字词内部再按字符线性分配，因此它是字幕边界估计，不是逐字声学对齐；关键动作仍需人工复核。

`build/` 及其成片、图像和诊断文件均是本机生成物，不随 Git 提交。本节所述验证数据、签名和大小是已交付版本的历史记录；在新电脑重建后应生成新的检查与人工复核，不把历史结果视为新运行的通过证明。
