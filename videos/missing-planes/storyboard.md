# 《没回来的飞机》动态叙事版：动作分镜与核对

内部制作记录。最终对用户只交付一个完整 MP4，不将本文件作为额外交付附件。

本记录按 `motion_opening.js`、`motion_inspection.js`、`motion_mechanism.js`、`motion_ending.js` 和 `motion_runtime.part` 的实际实现整理；字幕逐字取自 `motion/plan.json`，声音时点取自 `mix_motion.py`。动作描述以当前代码为准，计划文件只用于核对字幕、片名和总时长。

## 基本信息与观看路径

- 片名：没回来的飞机；主题：幸存者偏差；锚词：**缺席**。
- 成片规格：1920 × 1080，30 fps，4778 帧；音轨 159.250 秒，视频容器约 159.267 秒。
- 无口播；保留 28 组中文及英文字幕。英文以斜体显示。
- 深蓝黑环境、金属冷光、暖黄营业灯光、橙红损伤标记。变化来自主体动作、事件和记录变化。
- 叙事过程：受损飞机引出危险 → 营业店铺引出“留下者” → 返航记录产生疑问 → 比较不同飞行结果 → 展示记录如何被筛选 → 扩大观察范围 → 回到店铺与个人处境。
- 下表是代码中的绝对时间阈值，区间右端为下一段开始。30 fps 渲染会在不早于阈值的首帧呈现，一般量化误差小于一帧。第一个重拍例外：直接固定为零起算第 **511 帧，即 17.033333 秒**。
- 常规场景转场为约 0.55 秒的局部遮罩揭示：圆形扩展、横向擦入或水平带展开。`same` 段直接延续同一主体的位置变化，不额外做长时间双画面叠加。字幕区自 y = 845 向下独立保留。
