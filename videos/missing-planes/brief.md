# 没回来的飞机：已完成示例

- 主题：幸存者偏差。
- 认可版本：动态叙事版，2026-10-23；项目迁移日期：2026-10-26。
- 锚词：缺席。开头指没有进入观察的伤口和故事；结尾指应主动纳入判断的缺口。
- 开场主体：努力返航的受损飞机，螺旋桨动力不同、冒烟并修正姿态。
- 观众的问题：最危险的伤口为什么看不见？返航记录能代表所有出发者吗？
- 事件链：看见返航者 → 扫描并登记伤口 → 试贴装甲 → 发现资料缺口 → 展开出发名册 → 不同受损与返航结果 → 只有返航者被登记 → 观察范围收窄 → 重新纳入未被观察者 → 回到店铺和个人判断。
- 故事闭合：让观众从只看成功记录，转向追问记录如何被筛选；结尾把“缺席”重新定义为判断中要保留的位置。
- 画风：深蓝黑、冷色金属、暖金灯光和理解、橙红损伤、青色观察。飞机局部动作、受力反馈、顾客/门/店员动作与记录生成共同承担叙事。
- 音乐：本项目 assets/music 中的默认文件，159.250 秒，第 511 帧首高潮。
- 实际分镜、28 组双语字幕、8 处音效与事实表见 storyboard.md；旧字幕对象中的 visual/transition 是历史备注。
- reference/ 为已认可原成片；本项目重新渲染保存到 build/，不把历史记录当作新验证结果。

当前迁移只改善资源路径、工具配置和字体初始化，故事、字幕与主要场景保持认可版本。后续修改根据用户具体要求继续更新此目录。
