# 制作新短片的提示词

## 直接制作完整视频

先在当前会话打开克隆后的项目文件夹，再复制以下内容，只改主题和可选项。项目可位于任意电脑和目录：

```text
请使用当前会话已打开的 vibe-knowledge-video 项目，以根目录 AGENTS.md 和 README.md 所在位置为准。
先读取 AGENTS.md、README.md、docs/制作方案.md、docs/选题与叙事.md、docs/配音流程.md、docs/渲染与验收.md。

主题：{主题}
目标观众：普通人
音乐：默认使用项目 assets/music 中的《千年之后（氛围版）- 原谅他7次》，从 0 秒开始，保留尾奏。
交付目录：本期 videos/<slug>/build/；额外导出目录按我当次指定的位置。
配音：默认 Edge / 云健 zh-CN-YunjianNeural，中文，正常语速；试听文件只代表音色，正式内容重新合成。
要求：制作一支完整的带中文配音知识视频，16:9，1920×1080，30fps，中英双行字幕，音乐与少量音效。

采用“中文配音负责讲述，音乐负责情绪和大结构，动画负责展示过程，字幕帮助理解”的分工。音乐控制片长、段落与关键落点，旁白安排在合适的时间窗，不要求说满全片。配乐默认 music_mode=constant，固定增益并保留原曲自然动态；禁止每句话压低音乐、说完立即回升。先从约 −18dB 配乐增益调试，以实测和试听确定人声比例。只有确需改变叙事大段落时才设计缓慢过渡，不能恢复逐句闪避。

使用项目默认的深蓝黑风格、冷暖和明暗对比，用主体动作与可见结果解释知识。选择一条贯穿全片的主体线，按本主题重新设计物件、场景和事件；人物只在故事需要时使用，先检查比例、轮廓、五官与动作，避免未经设计的几何人形。先看开场、中段、结尾的风格帧，再扩展全片。有体积的物件应有一致的透视、受光和状态反馈；风格可根据我本次要求调整。当前段落配音与动作示例见 videos/phantom-jam，较早工程示例见 videos/missing-planes；都只参考实现，不照搬故事。

先从普通观众关心的问题出发，选一个贯穿全片的短词（锚词）和具体主体，写清观众的处境、前 3 秒正在发生的矛盾、完整事件链和结尾如何回答开头。研究并核对事实，再写分镜表：段落、时间码、主体动作、转场、中文旁白及入窗、中文字幕、英文字幕、音效；列出锚词全部位置。先向我展示简明方案，并在已有授权范围内继续推进；若我明确要求先讨论，就停留在方案阶段。

用 new --narrated 为新主题在 videos/<slug>/ 创建独立内容和场景代码，填写本期 narration.json、plan.json 和事实清单。不要继续创作《没回来的飞机》；示例只用于了解工程实现。让动作解释机制：事件发生后才出现对应结果或记录。只有平移缩放、粒子和呼吸动画不算完成主体动画。

先写适合听的完整语义段落，一个段落包含相互承接的数句，整段送入TTS；不要每条字幕单独合成。字幕独立分屏，不强求固定条数或3–5秒停留。按音乐大结构安排，再合成并实测时长，利用匹配的原生词边界或实际核对的标注对齐字幕与动作；基础 narrate 不自动完成这一步。原声切分覆盖全文，精炼字幕与旁白含义对应。普通衔接先从约0.2–0.6秒可听空隙调试，不每句机械空1–2秒；观察结果、高潮和结尾留白单独安排。保留段内自然停顿，正常语速、max_tempo=1.0，超窗先改文案或重排，不硬截或默认加速。TTS依赖安装在项目虚拟环境；ttsCN CLI用本机安装路径作为当次参数传入，不写死盘符、用户名或技能目录。已有音频缓存可离线复用。

每场展示触发、动作、反馈和结果，动作可以连续跨越字幕和段落。运动朝向与路径一致，部件、灯光和速度联动；停车、到达、选择等关键状态保持到观众能看清。“主体离开但问题仍在”等结论需要同框或连续可追踪的证据。转场检查遮罩前后相机与对象位置，不能突然跳远。使用模型时检查间距、数量、速度、传播方向和对照条件，说明简化和时间压缩；模型通过不等于真实实验被复现。本片专用对齐脚本、帧数和模型不能直接套用到新题。

默认音源第一高潮为零起算第 511 帧（17.033333 秒）。高潮前收暗和短暂停顿，当帧让关键结果、锚词和短冲击同时落下，稍后补术语。16.4–17.9 秒不安排人声；画面显示术语后再读出，片尾收束句之后保留自然尾奏。更换音源需重新实测和试听，并重设保护区，不能机械套用这些时码。

预览、看图、修正后再渲染。特别查开场、每种动作过程、密集画面、转场、16.3/16.8/17.0/17.1/17.5/18.0 秒以及第 510/511/512 帧。核对每句旁白的实际结束、字幕和动作对应、高潮人声留白以及句间配乐增益恒定。完成全片解码、规格、时长、真峰值、音轨封装同步与编码后抽帧检查。记录真实试听范围，不能把程序检查说成主观听感通过。

完成后只交付一个含中文配音、音乐和音效的完整 MP4，使用新版本文件名。分镜、配音时间轴、音频缓存、年份、人名、数字和引文核对表保留在本期目录。我已授权完成整个制作流程，不需要在例行渲染前再次确认。发送飞书或其他外部交付按我当次要求，不自动发送。
```

## 先沟通选题或方案

```text
请使用当前会话已打开的 vibe-knowledge-video 项目。
先读 AGENTS.md 和当前方案。围绕「{方向}」给我 3 个适合可视化、有完整故事的选题，说明处境、锚词、开场动作、核心转折、结尾和事实难点。需要查事实或当前参考时先搜索，并区分来源和自己的判断。现在只沟通方案，不编写完整动画、不渲染。
```

## 修改已有视频

```text
请继续当前 vibe-knowledge-video 项目下 videos/{已有slug} 的视频。
先读项目 AGENTS.md、本期 brief/research/storyboard、film.json、plan.json、narration.json（如有）和最近的人工复核记录。
本次修改：{具体问题与目标}。
保留已有主题、片名、音乐和已确认内容，按修改范围更新动作、字幕或混音。更新相应分镜与核对，抽帧修正后渲染新版本，不覆盖已交付成片。交付一个完整 MP4。
配音版保持 music_mode=constant，音乐不随每句旁白反复升降；修改配音时重合成受影响的语义段落，保留未变化的段落缓存，按实际时长重新核对该段及后续接缝、字幕和动作。旧逐句示例需要改善起腔时，应先合并为有语义的段落，再重新对齐。
```
