# 在其他会话复用

先在 Codex 中打开本项目所在目录。Skill 随仓库保存，无需安装到个人全局目录。以下提示词只需替换主题与本次要求。

## 制作新片

```text
使用 $vibe-video 制作一支完整知识短片。
主题：{主题}
面向：普通观众
希望观众带走的认识：{已有想法，或请你先研究确定}
本次特殊要求：{没有则使用项目默认值}
由当前会话负责完成。先验证代表性造型和关键动作，再做完整混音粗剪、返修及成片；把最新决定和待解决问题保存在本期 brief.md。
```

## 先讨论

```text
使用 $vibe-video，先讨论 {方向}，暂不开始制作。
给出三个具体切口，说明观众原本的直觉、看后认识、依据和可以怎样用画面展示，再推荐一个。
```

## 续做或局部修改

```text
使用 $vibe-video 接续 videos/{slug}。
先读本期 brief.md 的当前制作记录和最新 visual-review.md。
本次目标：{继续完成／要修改的具体问题}
保留已确认的其他取舍，更新受影响内容及检查记录。
```

若会话未列出该 Skill，直接让助手读取 `.agents/skills/vibe-video/SKILL.md`，或在本项目目录重新打开会话。无需复制旧会话的全部历史。项目位置可以不同，提示词不填写固定盘符。
