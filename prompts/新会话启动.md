# 制作新短片的提示词

## 直接制作完整视频

先在当前会话打开克隆后的项目文件夹，再复制以下内容，只改主题和可选项。项目可位于任意电脑和目录：

```text
请使用当前会话已打开的 vibe-knowledge-video 项目，以根目录 AGENTS.md 和 README.md 所在位置为准。
先读取 AGENTS.md、README.md、docs/制作方案.md、docs/选题与叙事.md、docs/渲染与验收.md。

主题：{主题}
目标观众：普通人
音乐：默认使用项目 assets/music 中的《千年之后（氛围版）- 原谅他7次》，从 0 秒开始，保留尾奏。
交付目录：本期 videos/<slug>/build/；额外导出目录按我当次指定的位置。
要求：制作一支完整的无口播知识视频，16:9，1920×1080，30fps，中英双行字幕，音乐与少量音效。

使用项目默认的深蓝黑风格、冷暖和明暗对比，用主体动作与可见结果解释知识。按本主题重新设计人物、物件、场景和事件；风格也可以根据我本次的要求调整。需要了解工程实现时，可查看 videos/missing-planes 下讲解幸存者偏差的示例。

先从普通观众关心的问题出发，选一个贯穿全片的短词（锚词）和具体主体，写清观众的处境、前 3 秒正在发生的矛盾、完整事件链和结尾如何回答开头。研究并核对事实，再写分镜表：段落、时间码、主体动作、转场、中文、英文、音效；列出锚词全部位置。先向我展示简明方案，并在已有授权范围内继续推进；若我明确要求先讨论，就停留在方案阶段。

为新主题在 videos/<slug>/ 创建独立内容和场景代码。让动作解释机制：事件发生后才出现对应结果或记录。只有平移缩放、粒子和呼吸动画不算完成主体动画。

默认音源第一高潮为零起算第 511 帧（17.033333 秒）。高潮前收暗和短暂停顿，当帧让关键结果、锚词和短冲击同时落下，稍后补术语。更换音源需重新实测和试听。

预览、看图、修正后再渲染。特别查开场、每种动作过程、密集画面、转场、16.3/16.8/17.0/17.1/17.5/18.0 秒以及第 510/511/512 帧。完成全片解码、规格、时长、音轨封装同步与编码后抽帧检查。记录真实试听范围，不能把程序检查说成主观听感通过。

完成后只交付一个含音乐和音效的完整 MP4，使用新版本文件名。分镜和年份、人名、数字、引文核对表保留在本期目录。我已授权完成整个制作流程，不需要在例行渲染前再次确认。
```

## 先沟通选题或方案

```text
请使用当前会话已打开的 vibe-knowledge-video 项目。
先读 AGENTS.md 和当前方案。围绕「{方向}」给我 3 个适合可视化、有完整故事的选题，说明处境、锚词、开场动作、核心转折、结尾和事实难点。需要查事实或当前参考时先搜索，并区分来源和自己的判断。现在只沟通方案，不编写完整动画、不渲染。
```

## 修改已有视频

```text
请继续当前 vibe-knowledge-video 项目下 videos/{已有slug} 的视频。
先读项目 AGENTS.md、本期 brief/research/storyboard、film.json、plan.json 和最近的人工复核记录。
本次修改：{具体问题与目标}。
保留已有主题、片名、音乐和已确认内容，按修改范围更新动作、字幕或混音。更新相应分镜与核对，抽帧修正后渲染新版本，不覆盖已交付成片。交付一个完整 MP4。
```
