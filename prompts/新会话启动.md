# 给其他 Codex 会话的启动提示词

## 直接制作完整视频

复制以下内容，只改主题和可选项：

```text
请使用本地项目 D:\projectdemo\vibe-knowledge-video。
先读取 AGENTS.md、README.md、docs/制作方案.md、docs/选题与叙事.md、docs/渲染与验收.md。

主题：{主题}
目标观众：普通人
音乐：默认使用项目 assets/music 中的《千年之后（氛围版）- 原谅他7次》，从 0 秒开始，保留尾奏。
交付目录：C:\Users\1\Videos
要求：制作一支完整的无口播知识视频，16:9，1920×1080，30fps，中英双行字幕，音乐与少量音效。

沿用本项目已确认的深蓝黑风格、冷暖和明暗对比、主体局部动作与因果动画。先看 videos/missing-planes/reference 中认可的动态叙事成片及 storyboard.md，学习节奏与动作关系。

先为本主题选锚词和具体主体，写清观众的处境、前 3 秒正在发生的矛盾、完整事件链和结尾如何回答开头。研究并核对事实，再写分镜表：段落、时间码、主体动作、转场、中文、英文、音效；列出锚词全部位置。先向我展示简明方案，并在已有授权范围内继续推进；若我明确要求先讨论，就停留在方案阶段。

为新主题在 videos/<slug>/ 创建独立内容，不要只替换飞机示例的字幕。让动作解释机制：事件发生后才出现对应结果或记录。只有平移缩放、粒子和呼吸动画不算完成主体动画。

默认音源第一高潮为零起算第 511 帧（17.033333 秒）。高潮前收暗和短暂停顿，当帧让关键结果、锚词和短冲击同时落下，稍后补术语。更换音源需重新实测和试听。

预览、看图、修正后再渲染。特别查开场、每种动作过程、密集画面、转场、16.3/16.8/17.0/17.1/17.5/18.0 秒以及第 510/511/512 帧。完成全片解码、规格、时长、音轨封装同步与编码后抽帧检查。记录真实试听范围，不能把程序检查说成主观听感通过。

完成后只交付一个含音乐和音效的完整 MP4，使用新版本文件名。分镜和年份、人名、数字、引文核对表保留在本期目录。我已授权完成整个制作流程，不需要在例行渲染前再次确认。
```
